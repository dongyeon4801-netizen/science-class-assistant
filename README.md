# 🧪 과학 수업 설계 비서 (내 노트북 전용)

배포하지 않고 **내 Windows 노트북에서만** 실행하는 프로그램입니다.

## 처음 한 번만
1. [python.org](https://www.python.org/downloads/)에서 파이썬을 설치합니다. 설치 화면에서 **"Add python.exe to PATH"**를 꼭 체크하세요.
2. 이 폴더를 노트북에 내려받습니다. GitHub에서 `Code → Download ZIP`을 누르고 압축을 풀면 됩니다.

## 실행
- **`실행하기.bat`을 더블클릭**하면 브라우저에 앱이 열립니다.
  - 첫 실행 때는 프로그램을 설치하느라 몇 분 걸릴 수 있어요.
- 검은 창을 닫으면 프로그램이 종료됩니다.
- 사이드바에 Gemini API Key를 입력하고 **💾 이 노트북에 Key 저장**을 누르면 다음부터는 입력하지 않아도 됩니다.

## 노트북에 저장되는 파일
| 폴더 | 내용 |
|---|---|
| `저장된_대화/` | 대화 기록이 자동으로 저장됩니다(JSON). 다시 실행해도 사이드바에서 불러올 수 있어요. |
| `결과물/` | AI 답변 아래의 **📄 Word(.docx)로 저장** 버튼으로 저장한 수업 자료가 들어갑니다. |

위의 두 폴더와 API Key(`.streamlit/secrets.toml`)는 GitHub에 올라가지 않습니다.
