# 생기부 작성 규칙

모든 비서(판독·작성·검수·맞춤법)가 따르는 공통 규칙이다. 규칙을 바꾸면 이 파일만 고친다.
기계적으로 확인 가능한 규칙은 `점검.py`가 자동으로 검사한다.

## 1. 근거 원칙 (가장 중요)

- 시트의 **체크 항목 · 교사 메모 · 활동지 판독 요약**에 있는 내용만 쓴다. 없는 활동·결과·성향을 만들어 내지 않는다.
- 학생이 활동지에 쓴 내용은 "무엇을 했는지"의 근거로만 쓴다. 학생의 자기평가 문장("나는 ~을 잘 이해했다")을 옮기지 않는다.
- 근거가 부족하면 문장을 늘리지 않고 짧게 끝낸다. **바이트를 채우려고 문장을 넣지 않는다.**
- 학생 이름은 어디에도 쓰지 않는다. 학년·반·번호로만 구분한다.

## 2. 문장 종결

- 모든 문장은 **관찰 가능한 행동을 나타내는 명사형(ㅁ 받침)으로 끝내고 온점을 찍는다.**
  - 예: `설명함.` `제시함.` `발표함.` `기록함.` `설계함.` `질문함.` `도움.` `정리함.` `수정함.` `참여함.` `맡아 수행함.` `연습함.` `~하기 시작함.` `역할을 맡음.`
- 쓰지 않는 종결·표현 (속마음, 평가, 과장):

| 금지 | 이유 | 바꾸는 방법 |
|---|---|---|
| 보임 / 돋보임 / 모습을 보임 | 무엇을 했는지가 비어 있음 | 실제 행동을 쓴다: "2학기에는 모둠 결과를 직접 발표함." |
| 이해함 / 깨달음 / 알게 됨 | 머릿속은 관찰 불가 | "~을 그림으로 나타내어 설명함." |
| 느낌 / 생각함 / 흥미를 가짐 | 감정·내면 | "관련 자료를 추가로 찾아 정리함." |
| 노력함 | 내면 | "~을 연습함." "~하기 시작함." |
| 성장함 | 근거 없는 평가 | 변화 전·후 행동을 쓴다 |
| 뛰어남 / 탁월함 / 우수함 / 역량 / 잠재력 / 인상적 / 깊이 있는 | 과장, AI 상투어 | 삭제하고 사실만 남긴다 |

## 3. 문체

- 과장 없이, 짧고 정확하게. 한 문장에 행동 하나.
- 같은 반 학생들 사이에 똑같은 문장이 반복되지 않게 한다 (`점검.py`가 검사).
- 영문은 쓰지 않는다. 과학 단위·기호(mL, g, cm, ℃, pH 등)는 예외.
- 교사 문체는 `문체가이드.md`를 따른다. 학생이 한 말·질문은 작은따옴표로 인용하고, 날짜는 `(2025.07.07.)`처럼 끝 온점까지 찍는다.
- `~할 수 있음.`(능력 추정), `인상 깊음.`(교사 감상)도 쓰지 않는다.

## 4. 기재하지 않는 것 (기재요령)

교내외 수상·대회, 인증시험·자격증 점수, 논문·학회·특허·출판, 해외 활동·어학연수, 부모(가족)의 직업·지위,
사교육(학원·과외) 관련 내용, 특정 대학·기관·상호명, 교내 대회 참가·성적, 방과후학교 참여,
정신건강·질병 관련 서술, 출결(지각·결석 — 출결 상황란에 기록). `점검.py`가 대표 단어를 검사하지만 최종 확인은 교사가 한다.

## 5. 분량

- 상한: 세특·자율·행동특성 각 **1,500바이트**(한글 500자). 학교 기재요령과 다르면 `점검.py`의 `LIMIT_BYTES`와 시트 스크립트의 `LIMIT_BYTES`를 같이 고친다.
- 바이트 계산(나이스 기준): 한글·특수문자 3, 영문·숫자·공백·온점 1, 줄바꿈 2.
- 하한은 없다. 근거만큼만 쓴다.

## 6. 영역별 규칙

### 과목별 세부능력 및 특기사항 (과학, 중1·중3)
- 순서: 활동(활동지 주제·단원) → 수행한 행동(체크 A·B) → 소통·협력(C) → 확장(D)·교사 메모.
- 활동지 판독 요약에서 **학생이 실제로 한 것**(설계한 변인, 그린 그래프, 제시한 원인 등)을 구체적으로 한 가지 이상 넣는다.
- 교사 메모에 "좋은 질문" 등이 있으면 질문 내용을 그대로 살려 쓴다.

### 자율활동 (중3 담임)
- 역할(임원·부서) → 개인 행동(체크) → 참여 행사.
- 행사 문장은 `행사목록` 탭에 교사가 적은 **공통 문구만** 사용한다. 행사 내용을 지어내지 않는다.

### 행동특성 및 종합의견 (중3 담임)
- **인성 · 교우관계 · 학업 · 개별 특성** 4개 영역을 모두 포함한다. 근거(체크·메모)가 없는 영역은 쓰지 않고 검수경고에 `○○ 영역 근거 없음`을 남긴다.
- 교사의 **구체 사례 메모**를 중심 문장으로 쓰고, 체크 항목은 이를 뒷받침하게 쓴다.
- **보완점 규칙**
  1. 솔직하게 쓴다: "~하는 데 어려움이 있음", "~이 아직 서툼", "~하는 경우가 있었음".
  2. 뒤에 관찰된 변화·시도를 행동으로 붙인다: "~하기 시작함." "~을 연습함." "~하는 횟수가 늘어남."
  3. 변화 사례 메모가 없으면 지어내지 않는다 → 검수경고 `보완점 변화 사례 없음`.
  4. 학생당 최대 1개, 강점 문장 사이에 둔다 (마지막 문장에 두지 않는다).

## 7. 비서 흐름

| 순서 | 비서 | 하는 일 |
|---|---|---|
| ① | `sgb-reader` 판독 | 활동지 PDF → 판독 요약. 불확실한 글자는 `[?]` |
| ② | `sgb-writer` 작성 | 시트 행 + 판독 요약 + 문체 → 초안 |
| ③ | `sgb-reviewer` 검수 | 근거 대조, 금지 표현, 4영역·보완점 규칙, `점검.py` |
| ④ | `sgb-speller` 맞춤법 | 맞춤법·띄어쓰기·종결 온점 최종 확인, `점검.py` 재실행 |

| ⑥ | `붙여넣기도우미.html` | 확정본을 번호 순으로 클립보드에 올림 → 교사가 나이스에 붙여넣기 |
