# 생기부 비서 사용법

## 처음 한 번
1. 구글 드라이브에서 빈 구글 시트를 만든다 (예: `2026 생기부 작업`).
2. 확장 프로그램 → Apps Script → `시트설정.gs` 내용 전체 붙여넣기 → 저장.
3. 시트 새로고침 → 메뉴 **[생기부 비서] → ① 시트 만들기** (처음에 권한 허용 창이 뜨면 허용).
   → 탭: 세특_중1(1-1, 1-4) · 세특_중3(3-6, 3-7, 3-8) · 자율_중3(3-7) · 행발_중3(3-7) · 행사목록
4. 자율을 쓸 때는 `행사목록` 탭에 행사와 공통 문구를 먼저 적는다.

## 매번
| 단계 | 선생님 | Claude |
|---|---|---|
| 1 | 시트에서 체크 클릭, 메모 입력 | |
| 2 | 활동지 PDF를 채팅에 올림 (파일명 `3-7-05_활동1.pdf` 권장, 이름은 가리기) | |
| 3 | "○반 초안 써줘" | 판독 → 작성 → 검수 → 맞춤법 비서 순서로 실행, 반별로 동시에 처리 |
| 4 | | 드라이브에 `초안_<탭>_<날짜>` 시트를 만들고 주소 전달 |
| 5 | 메뉴 **② 초안 불러오기** → 주소 붙여넣기 | |
| 6 | `최종본` 열 수정, `검수경고` 확인 → `확정` 체크 | |
| 7 | 메뉴 **③ 입력용 내보내기** → 파일 → 다운로드 → CSV | |
| 8 | 나이스 PC에서 `붙여넣기도우미.html`을 열고 CSV 불러오기 → 한 명씩 Ctrl+V | |

- ② 초안 불러오기는 **확정된 학생과 이미 고친 최종본은 덮어쓰지 않는다.**
- 나이스 PC가 인터넷이 안 되는 업무망이면 `붙여넣기도우미.html`과 CSV를 망연계(자료 전송)로 옮긴다. 도우미는 인터넷 없이 동작한다.
- 작성 규칙: `작성규칙.md` / 자동 점검: `python3 생기부/점검.py 초안.csv`
