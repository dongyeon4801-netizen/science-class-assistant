# 교사 문체 가이드

교사가 제공한 2024~2025 자율·과학 세특·행동특성 샘플에서 뽑은 문장 패턴이다.
원문과 학생 이름은 넣지 않았고, 예문은 패턴을 보여 주려고 새로 쓴 것이다.
**작성규칙.md와 부딪히면 작성규칙이 우선**한다 (아래 "바꿔 쓰기" 표 참고).

## 공통으로 살릴 것

- 한 문장에 [상황·활동] → [구체 내용] → [행동 종결] 순서.
  - 예: "`~을 통해` / `~에서` + 무엇을 + `~함.`"
- 연결 어미: `~하고`, `~하며`, `~하여`, `~을 기반으로`, `~을 중심으로`, `이를 바탕으로`, `나아가`, `특히`
- 학생이 한 말·질문·정의는 **작은따옴표로 그대로 인용**한다.
  - 예: `'상대방이 싫어하면 폭력이다'라고 정의함.` / `'~은 무엇일까?'라는 질문을 만듦.`
- 날짜는 `(2025.07.07.)` 형식으로, 마지막 온점까지 찍는다. 기간은 `(2025.03.01.-2025.08.13.)`.
- 교사가 자주 쓰는 관찰 어휘: 발표함, 제시함, 정의함, 규정함, 설명함, 제작함, 조사함, 기록함, 소개함, 주장함, 이행함, 맡음, 도움, 작성함, 인용함.

## 영역별 뼈대

### 자율활동 (교육·행사형)
1. `교육명(날짜)을 통해` 또는 `교육명(날짜)에서`
2. 학생이 제시·정의·소개한 **구체 내용** 1~2가지 (소감문·활동지에서)
3. 결과물 종결: `~는 소감문을 작성함.` / `~다짐을 발표함.` / `~계획을 보고서에 기록함.`

- 예: `학교폭력예방교육(2025.09.02.)에서 장난과 폭력의 기준을 '한 명이라도 불편하면 폭력'이라고 정의함. 목격 시 담임교사에게 알리겠다는 행동 계획을 소감문에 작성함.`

### 자율활동 (역할형)
- `○학기 학급 학생자치회 부회장(기간)으로서` → 실제로 한 일 → 결과.
- 예: `2학기 학급 부회장(2025.08.14.-2026.02.28.)으로서 점심시간 급식 줄 인솔을 맡아 매일 수행함.`

### 과학 세특 (프로젝트·수업형)
1. `[프로젝트명]을 통해 [맡은 대상]을 조사함.`
2. 조사·탐구한 **구체 내용**: 무엇을 어떤 기준으로(`~을 중심으로 조사함.`)
3. 산출물·발표: `이를 기반으로 ~ 프레젠테이션을 제작함.` / `발표 시 ~함.`
4. 수업 활동(교사 메모): 학생이 만든 질문을 인용하고, 입자 모형 표현, 실생활 예시 제시 등을 씀.

- 예: `'물질의 상태 변화' 수업에서 가열 곡선 자료를 해석하여 녹는점과 끓는점을 찾고, 온도가 일정한 구간이 나타나는 이유를 입자 배열 변화와 연결하여 서술함.`

### 행동특성 및 종합의견
- 교사 샘플의 순서: 성격 요약 → 인성(예의·규칙) → 보완점과 변화 → 교우관계 → 학업 → 개별 특성(관심·특기·역할) → 마무리
- 교우관계 표현은 샘플 어휘를 살린다: `좁고 깊은 교우관계를 형성함`, `두루두루 원만하게 지냄`
- 보완점 뼈대 (샘플에 이미 있는 좋은 패턴):
  - `~한 언행으로 지도를 받은 적이 있으나, 이후 ~함.`
  - `학기 초 ~하였으나, 2학기에는 ~하는 횟수가 줄어듦.`

## 바꿔 쓰기 (샘플 문체 → 규칙 적용)

| 샘플에 자주 나온 표현 | 문제 | 이렇게 바꿈 |
|---|---|---|
| `~하는 모습을 보임.` / `~태도를 보임.` | 보임 금지 | 그 행동 자체로 끝냄: `~함.` |
| `~이 인상 깊음.` / `인상적임.` | 교사 감상 | 삭제하고 행동만 남김 |
| `~할 수 있음.` | 능력 추정 | 실제로 한 것만: `~을 설명함.` |
| `노력함` / `노력하는 성품을 지님` | 내면 | 한 행동: `~을 연습함.` `~하기 시작함.` |
| `알게 됨` / `깨달음` / `이해함` / `느낌` | 내면 | 결과물 종결: `~는 소감문을 작성함.` (학생이 쓴 내용임을 밝힘) |
| `뛰어난 ~ 역량` / `돋보임` / `우수한` / `탁월한` | 과장 | 삭제 |
| `예쁜 학생임` / `사랑스러운` / `맑은 눈빛` | 교사 주관 | 삭제 |
| `~기여함` / `~이바지함` | 효과 추정 | 무엇을 했는지 먼저 쓰고, 꼭 필요할 때만 유지 |

**가장 중요한 변환:** 자율 샘플의 `~을 깨닫고 ~소감문을 작성함.`은 괜찮습니다. 깨달음의 주체가 학생이고, 교사가 본 것은 "소감문 작성"이기 때문입니다. 그래도 `깨닫고`는 `~라고 쓰고`, `~을 제시하고`로 바꾸는 것을 기본으로 합니다.

## 기재하지 않는 것 (샘플에서 발견)

- 정신건강·질병 관련 서술 (우울감, 심리적 불안, 질병 결석)
- 출결 사항 (지각·결석은 출결 상황란에 기록되므로 행발에 쓰지 않음)
- 교내 대회 참가·성적 (e-스포츠 대회, 골든벨 성적 등)
- 방과후학교 참여
- 같은 반 안에서 통째로 반복되는 문장. 학급 공통 활동(예: 자율학습 챌린지)은 `행사목록` 공통 문구로만 쓴다.
